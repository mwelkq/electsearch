# Форма для збору запитів (Google Form)

Мета: отримати 30–50 **нових** запитів, яких система не бачила під час розробки, і на них один раз чесно оцінити фінальну конфігурацію (без жодних змін після цього).

---

## Текст форми (скопіювати в Google Forms)

**Назва:** Що б ви шукали на сайті факультету?

**Опис:**
> Привіт! Я роблю курсову — пошуковий помічник для сайту факультету electronics.lnu.edu.ua (на самому сайті пошуку немає). Допоможіть зібрати реальні запитання, щоб перевірити, як система з ними справляється.
>
> Напишіть 3–5 запитань так, як ви б написали їх у пошук або чат: можна розмовно, скорочено, з абревіатурами, з помилками — як вам звично. Займе 2 хвилини. Анонімно.

**Питання 1** (абзац, обов'язкове)
Що ви шукали або могли б шукати на сайті факультету? Кожне запитання — з нового рядка.
*Підказка під полем:* наприклад, про розклад, навчання, викладачів, вступ, документи, практику, події.

**Питання 2** (кілька варіантів, необов'язкове)
Хто ви?
- Студент(ка) бакалаврату
- Студент(ка) магістратури / аспірант(ка)
- Викладач(ка) / працівник(ця)
- Абітурієнт(ка) або інше

**Питання 3** (абзац, необов'язкове)
Чи було, що ви не змогли щось знайти на сайті? Що саме?

---

## Правила, щоб оцінка була чесною

1. **Не дивитись результати системи, поки не розмічено еталон.** Спершу для кожного запиту вручну знайти на сайті правильну сторінку (або позначити «на сайті немає»), і лише потім запускати оцінку.
2. **Нічого не змінювати в системі після прогону** на цих запитах — це фінальна, «контрольна» цифра. Будь-яке покращення після неї вимагає ще одного нового набору.
3. Запити не редагувати (помилки й суржик лишаємо — це і є реальні запити). Дублікати й запити не про факультет — окремо (останні йдуть як «пастки»).
4. Еталон краще розмітити вдвох (Марта + ще хтось) хоча б на частині запитів і порахувати узгодженість (κ Коена).

## Як додати в набір

Кожен запит — запис у `eval/queries.json` з `"set": "user"`, наприклад:

```json
{"id": "u001", "set": "user", "category": "nav_colloquial", "query": "де глянути розклад сесії",
 "relevant": ["https://electronics.lnu.edu.ua/students/rozklad-format-pdf/"], "note": "", "reviewed": true}
```

Оцінка (після розмітки):

```bash
python eval/evaluate.py --set user --expand --tag user_final
```

```bash
python eval/evaluate_rag.py --set user --model gemini-3.1-flash-lite --tag rag_user_final
```
