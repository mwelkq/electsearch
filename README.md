# Вебпомічник навігації сайтом факультету

Курсова робота: «Розробка та дослідження методів пошуку інформації для вебпомічника навігації сайтом із використанням великих мовних моделей».

Користувач ставить питання звичайною мовою («де подивитись розклад пар», «навчальний план ІПЗ»), а система знаходить сторінки сайту [Факультету електроніки та комп'ютерних технологій ЛНУ](https://electronics.lnu.edu.ua/) і повертає посилання на рекомендовану сторінку з коротким поясненням. По суті, це маленький пошуковик для одного сайту (на самому сайті пошуку немає).

## Як це працює

```
crawler.py ─► data/pages.jsonl ─► process.py ─► data/chunks_v2.jsonl
   (сторінки сайту)                (фрагменти + шлях розділу)
                                            │
            запит ─► query_expansion.py ─► search.py ─┬─ BM25 (search_bm25.py, лематизація pymorphy3, поле «заголовок»)
                     (абревіатури, синоніми)           ├─ embeddings (multilingual-e5-small)
                                                       └─ гібрид (Reciprocal Rank Fusion)
                                                                 │ топ-8 сторінок
                                                                 ▼
                                                    rag.py ─► Gemini ─► рекомендована сторінка + пояснення
                                                                 │
                                         api.py (FastAPI) ─► web/index.html (чат)
```

| Файл | Що робить |
|---|---|
| `crawler.py` | обходить сайт від головної сторінки за посиланнями, зберігає текст сторінок |
| `process.py` | чистить текст, прибирає дублікати й пагінацію, ріже на фрагменти, додає «хлібні крихти» |
| `search_bm25.py` | BM25 з лематизацією українською і окремою вагою заголовка (спрощений BM25F) |
| `search.py` | embeddings, гібридний пошук RRF, єдиний інтерфейс `Searcher` |
| `query_expansion.py` | розшифровка абревіатур (ІПЗ, КН, ІСТ, ВПК) і синоніми |
| `rag.py` | промпт, виклик Gemini, перевірка, що рекомендований URL справді є серед знайдених |
| `api.py` | бекенд: `/ask`, `/search`, `/health`, `/feedback`, інтерфейс на `/` |
| `web/index.html` | чат-інтерфейс (HTML/CSS/JS без фреймворків) |
| `eval/` | тестові запити, оцінка пошуку (`evaluate.py`) і RAG (`evaluate_rag.py`), результати |
| `journal_kursova.md` | журнал роботи: рішення, проблеми, усі експерименти з цифрами |

## Запуск локально

Потрібен Python 3.12.

```bash
pip install -r requirements.txt
```

Ключ Gemini (безкоштовний, з Google AI Studio) покладіть у файл `.env` поруч із кодом:

```
GEMINI_API_KEY=ваш_ключ
```

Запуск сервера:

```bash
uvicorn api:app --port 8000
```

Відкрийте http://127.0.0.1:8000. Перший запуск рахує вектори для 3 493 фрагментів (~8 хв на CPU) і зберігає їх у `data/`, далі сервер стартує за кілька секунд.

Без ключа працює лише пошук (`/search`); `/ask` поверне помилку 503, а якщо Gemini тимчасово недоступна, інтерфейс покаже результати пошуку без пояснення («режим без мовної моделі»).

## Запуск на сервері (Docker)

```bash
docker build -t electsearch .
```

```bash
docker run -d -p 8000:8000 -e GEMINI_API_KEY=ваш_ключ -v electsearch-data:/app/data/runtime --name electsearch electsearch
```

Модель і вектори рахуються під час збирання образу, тож контейнер стартує швидко. Відгуки користувачів і журнал запитів пишуться в том `electsearch-data`. За nginx чи іншим проксі додайте `-e TRUST_PROXY=1`.

### Змінні середовища

| Змінна | За замовчуванням | Що задає |
|---|---|---|
| `GEMINI_API_KEY` | з `.env` | ключ Gemini |
| `GEMINI_MODEL` | `gemini-3.1-flash-lite` | модель для відповідей |
| `ASK_LIMIT_PER_MIN` | `10` | ліміт `/ask` на хвилину з однієї адреси (квота Gemini спільна для всіх) |
| `ALLOWED_ORIGINS` | порожньо | CORS, якщо інтерфейс розміщено на іншому домені (через кому) |
| `TRUST_PROXY` | `0` | `1`, якщо сервіс за проксі (IP береться з `X-Forwarded-For`) |
| `LOG_QUERIES` | `1` | анонімний журнал запитів `queries_log.jsonl` (без IP) — для оцінки на реальних запитах |
| `RUNTIME_DIR` | `data/` | тека для відгуків і журналу |
| `CHUNKS_PATH` | `data/chunks_v2.jsonl` | індекс |

## Повторити експерименти

```bash
python eval/evaluate.py --only-reviewed --expand
```

```bash
python eval/evaluate_rag.py --model gemini-3.1-flash-lite --only-reviewed
```

Корисні прапорці: `--methods bm25` (без моделі embeddings), `--no-lemma` (гіпотеза H4), `--title-weight 0` (без поля «заголовок»), `--set heldout --include-unreviewed` (контрольний набір). Пошук з консолі: `python search.py "як навчатися заочно"`.

Оновити знімок сайту й індекс:

```bash
python crawler.py
```

```bash
python process.py --out data/chunks_v2.jsonl
```

## Результати (19.11.2026, 52 запити з відповіддю + 4 запити-пастки)

| | Hit@1 | Hit@5 | MRR |
|---|---|---|---|
| BM25 | 0.750 | 0.962 | 0.836 |
| Embeddings (e5-small) | 0.673 | 0.904 | 0.775 |
| Гібрид (RRF) | 0.769 | 0.981 | 0.867 |

RAG (гібрид, 8 сторінок, gemini-3.1-flash-lite): правильна сторінка в 0.981 випадків (перша версія — 0.827), вигаданих посилань 0, усі запити поза темою сайту відхилено. Обмеження: частину покращень підбирали на тому самому наборі запитів, тому потрібна перевірка на нових запитах; деталі й довірчі інтервали — у `journal_kursova.md`.

## Обмеження

- Знімок сайту від 29.10.2026; PDF-файли не індексуються; з архіву новин зібрано лише частину.
- Безкоштовний тариф Gemini має ліміти й буває перевантажений (503/429) — тоді працює режим без мовної моделі.
